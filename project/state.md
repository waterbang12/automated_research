## Architecture

```
researcher -> hypotheses -> coder -> sandbox (Docker) -> trusted scorer -> analyst
     ^          (+ decision record)                                         |
     +----------- SQLite memory (records, steps, decisions, costs) <--------+
                         |
            research graph + run trace + checks -> read-only web viewer
```

| Component | File | Role |
|---|---|---|
| CLI | `research/__main__.py` | `build-sandbox`, `new-domain`, `check-domain`, `run`, `report`, `show`, `permissions`, `graph {build,export,serve}` |
| Controller | `research/controller.py` | Worker pool, limits, budget stop, resume, approvals. Records every step to `agent_steps`. |
| Researcher | `research/researcher.py` | Proposes N hypotheses from the full history, plus a **decision record** per round. |
| Coder | `research/coder.py` | Writes one program per hypothesis and repairs it on failure (`max_fix_attempts`). |
| Executor | `research/executor.py` | Docker with `--network none`, a read-only root filesystem, all capabilities dropped, a non-root uid, and memory, CPU, pid and time limits. |
| Evaluator | `research/evaluator.py` | Scores with the domain's trusted scorer. Success = improvement ≥ `min_improvement`. The analyst LLM only comments. |
| LLM layer | `research/llm.py` | Providers: `anthropic`, `openai`, `claude-cli`, `codex-cli`, `offline`. Schema validation plus re-ask, worst-case budget reservation, and cost logging. |
| Schemas | `research/schemas.py` | `HYPOTHESES` (with `decision`, `falsified_if`), `CODE`, `ANALYSIS`. Strict: all keys required, no extra keys. |
| Memory | `research/memory.py` | SQLite tables: `runs`, `hypotheses`, `experiments`, `code_versions`, `executions`, `llm_calls`, `approvals`, `permission_requests`, `agent_steps`, `research_decisions`. Columns are added with `ALTER`, so older databases keep working. |
| Domains | `research/domain.py`, `domains/*/` | Problem definitions: `domain.toml` (objective, metric, contract), `prepare.py`, `scorer.py`, `baseline.py`, an optional `data/` (mounted at `/raw`), and an optional `offline_fixture.py`. |
| Problem tooling | `research/scaffold.py` | `new-domain` (scaffolds a domain from a CSV) and `check-domain` (no-LLM soundness checks). |
| Research graph | `research/graph.py` | Derives the reasoning graph from the records into the `graph_nodes`/`graph_edges` tables (additive). Lineage queries, paired statistics, narrative export. |
| Run trace and checks | `research/steps.py` | Timeline (recorded, or reconstructed for older runs), step detail, nine run checks. |
| Viewer | `research/viewer_server.py`, `viewer/` | Stdlib HTTP server bound to 127.0.0.1. Pages: a Run page (default) and a Graph view with replay. React Flow is vendored, so there is no build step. |

Domains present:
- `digits`: scikit-learn 8×8 digits, accuracy, with an offline fixture.
- `planted`: synthetic regression with a known best RMSE of about 0.5, generated by `examples/planted_regression.py`.

Configs: `configs/*.toml`, one per provider or demo. `runs/` holds local run databases and workspaces. It is gitignored, so each person's runs stay on their own machine. Samples generated from real runs are committed under `docs/sample-*`.

## Environment it was verified in

Windows 11, Python 3.13 in `.venv`, Docker Desktop with the image `autoresearch-sandbox:1`
(Python 3.12, numpy, scipy, scikit-learn, pandas), and Claude Code CLI 2.1.299. The Codex CLI
0.162.1 was installed only in a scratch directory to check its interface. It is not installed on
the owner's machine, and no signed-in Codex run has been made.

## Test suite

68 tests in `tests/`, all passing at the time of writing (`.venv\Scripts\python -m pytest -q`).
The tests in `test_docker_sandbox.py` and `test_scaffold.py::test_check_domain_end_to_end_in_docker`
use real Docker and skip when it is unavailable. No test calls a paid API; the providers are
exercised against local fakes.
